# JR四国非公式アプリ プライバシーポリシー

最終更新日：2026年7月14日

本プライバシーポリシー（以下「本ポリシー」）は、harukin／Xprocess（以下「開発者」）が提供する「JR四国非公式アプリ」（以下「本アプリ」）におけるユーザー情報の取り扱いを定めるものです。

本アプリは、四国旅客鉄道株式会社（JR四国）およびその関連会社とは関係のない非公式アプリです。

## 1. 取得・利用する情報

### 1.1 端末内で利用する情報

次の情報は、該当機能の提供を目的として端末内で取得・保存します。開発者のサーバーへ送信する処理は行いません。

#### 位置情報

- 現在地、最寄り駅および地図上の現在地を表示するために利用します。
- アプリを使用している間にのみ取得し、定期的に表示を更新します。
- 利用は任意です。許可しない場合、最寄り駅の自動検出など一部機能が制限されます。

#### ICカードデータ（NFC／FeliCa）

- 対応端末で、交通系ICカードのIDm、残高、システムコード、利用履歴を読み取ります。
- 読み取った情報は端末内に保存し、アプリやウィジェットでの表示に利用します。
- IDm、残高、利用履歴を開発者のサーバーへ送信する処理は行いません。

#### ユーザー設定・お気に入り

- お気に入り駅、テーマ、レイアウト、通知項目、カスタマイズなどの設定を端末内に保存します。
- WebViewで外部サイトへログインした場合、Cookieなどのセッション情報がWebViewのストレージに保存される場合があります。

### 1.2 通知機能で送信する情報

プッシュ通知を有効にした場合、次の情報を通知の配信と設定管理のために送信・保存します。

- Expo Push Tokenなど、アプリまたは端末に関連する通知用識別子
- 遅延速報、運行情報、列車情報など、ユーザーが選択した通知項目
- 通知の登録・配信に必要な技術情報

通知用識別子を氏名やメールアドレスと意図的に関連付けることはありません。

### 1.3 障害解析・品質改善のために送信する情報

本アプリは、障害解析および品質改善のためにSentryを利用します。Sentryへ送信される可能性がある情報には、次のものがあります。

- クラッシュ、エラー、スタックトレースおよびエラーメッセージ
- アプリのバージョン、OS、端末種別などの技術情報
- 通信先のホスト名、処理時間、HTTPステータスなどの通信診断情報
- アプリ内の画面遷移、タップなどの操作状況
- パフォーマンスおよびアプリの動作状態
- IPアドレス、Cookieその他Sentry SDKが既定の個人関連情報として付加する情報
- 障害発生時またはサンプリング対象となったセッションの画面操作・表示状態（Session Replay）
- ユーザーがSentryのフィードバック機能を通じて任意に入力した内容

通信エラーの調査時には、取得したレスポンス本文の先頭部分が診断情報に含まれる場合があります。開発者は、不要な個人情報や機密情報を意図的に送信しないよう実装上の制限と運用上の対策を行います。

Sentryによる情報の取り扱いについては、[Sentryのプライバシーポリシー](https://sentry.io/privacy/)をご確認ください。

### 1.4 ユーザーが任意で投稿する情報

駅・番線情報などの投稿機能を利用した場合、次の情報を開発者のサーバーへ送信します。

- 路線、駅、地点を識別する情報
- 乗り場、番線などユーザーが入力した情報
- 投稿時にユーザーが入力した説明文

投稿は任意であり、利用しなくても本アプリの基本機能は利用できます。投稿欄には氏名、連絡先、ICカード情報などの個人情報を入力しないでください。誤った投稿については、アプリ内の削除要求機能またはサポート窓口から削除を依頼できます。

## 2. 利用目的

取得した情報は、次の目的で利用します。

- 現在地・最寄り駅・地図の表示
- ICカード残高・履歴およびウィジェットの表示
- お気に入り、表示設定などの保存
- 列車遅延、運行情報などのプッシュ通知
- 投稿された駅・番線情報の確認、反映および修正
- クラッシュ、不具合および通信障害の調査
- アプリの性能、安定性、操作性および機能の改善
- 不正利用の防止とサービスの安全な運営

## 3. 外部サービスと第三者提供

本アプリは次の外部サービスを利用します。これらの事業者は、開発者の委託先または独立したサービス提供者として、それぞれの規約とプライバシーポリシーに基づいて情報を処理する場合があります。

| サービス | 主な用途 | 提供者 |
| --- | --- | --- |
| Sentry | 障害解析、性能監視、Session Replay、フィードバック | Functional Software, Inc. |
| Google Maps SDK | 地図表示 | Google LLC |
| Firebase Cloud Messaging | Androidのプッシュ通知基盤 | Google LLC |
| Apple Push Notification service | Apple端末のプッシュ通知基盤 | Apple Inc. |
| Expo Push Notifications | プッシュ通知トークンの発行・配信 | 650 Industries, Inc.（Expo） |
| Expo Updates | OTAアップデートの確認・配信 | 650 Industries, Inc.（Expo） |

開発者は、取得した情報を販売しません。法令に基づく場合、生命・身体・財産の保護に必要な場合、またはサービス提供に必要な委託先へ取り扱いを委託する場合を除き、ユーザー情報を第三者へ提供しません。

## 4. WebViewと外部コンテンツ

本アプリは、JR四国公式サイト、Google Maps、鉄道運用Hub、えれサイトなどの外部サイト・外部データソースをWebViewまたはブラウザで表示する場合があります。

外部サイトへのアクセス時には、IPアドレス、Cookie、アクセス情報などを各提供元が取得する場合があります。外部サービス上でログインまたは情報を送信した場合、その情報は各提供元の規約とプライバシーポリシーに従って取り扱われます。

開発者が、外部サービスのパスワードを取得または管理することはありません。

## 5. データの保存期間

- 端末内の設定、お気に入り、ICカードデータ、キャッシュなどは、ユーザーが削除するか、アプリをアンインストールするまで保存されます。
- プッシュ通知トークンと通知設定は、削除依頼を受けるまで、トークンが無効になるまで、または通知サービスを終了するまで保存します。
- 投稿情報は、内容が不要になるまで、削除要求を処理するまで、またはサービスを終了するまで保存する場合があります。
- Sentryへ送信された情報は、Sentryプロジェクトに設定された保存期間または障害調査に必要な期間保存されます。

## 6. データの削除と利用停止

### 端末内データ

アプリのアンインストール、または端末の設定からアプリデータを消去することで削除できます。

### 位置情報・通知

端末の設定から権限を無効にできます。通知カテゴリはアプリ内の通知設定から変更できます。

### サーバーに保存されたデータ

プッシュ通知トークン、通知設定、任意投稿または問い合わせに関連するデータの削除を希望する場合は、[サポートページ](/JR-shikoku-Apps-Common/support/)に記載した窓口へご連絡ください。対象の特定に必要な情報をご案内する場合があります。

## 7. セキュリティ

本アプリが開発者のサーバーおよび外部サービスへ情報を送信する際は、原則としてHTTPSによる暗号化通信を使用します。開発者は、情報の漏えい、紛失、改ざんおよび不正アクセスを防ぐため、合理的な安全管理措置を講じます。

ただし、インターネットを通じた通信や電子的な保存の安全性を完全に保証することはできません。

## 8. 児童のプライバシー

本アプリは特定の年齢層を対象としたサービスではなく、児童から氏名や連絡先などの個人情報を意図的に収集するものではありません。児童の個人情報が意図せず送信されたことが判明した場合は、確認のうえ削除などの対応を行います。

## 9. 広告とトラッキング

本アプリは広告配信サービスを使用しておらず、第三者のアプリやWebサイトをまたいだ広告目的のトラッキングを行いません。

障害解析と品質改善のためにSentryを使用しますが、広告配信や広告プロファイルの作成を目的とするものではありません。

## 10. 本ポリシーの変更

機能、利用するサービスまたは法令等の変更に応じて、本ポリシーを変更する場合があります。重要な変更は、アプリ内のお知らせまたは本Webサイトで案内します。
