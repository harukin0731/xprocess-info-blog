# Ver.7.2.2 → 7.3 お知らせ準備

## 比較範囲

- 7.2.2 = `master`（3db2184 で設定画面の表示を 7.2.2 に変更、5b9e400 で master に取り込み）
- 7.3 = 現在の `develop`（1029f03、2026-10-14）。master..develop の非マージコミット107件
- タグは無い。`app.json` の version は 7.2、設定画面の `versionCode` は "7.2.2" のまま → **7.3 への番号更新はまだ**
- `package.json` のネイティブ依存の追加は無く（Web版依存の削除のみ）、runtimeVersion は sdkVersion のまま → **OTA配信で出せる見込み**（推測）

## 掲載方針

- 速度改善と描画エラー対策は告知に掲載しない
- 内部データの種別追加は公開しない
