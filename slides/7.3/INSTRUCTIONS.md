# Ver7.3 アップデートお知らせ 作業手順

## ファイルの役割

- `slides.md`：7枚の本文と記事固有の表示設定
- `style.css`：スクショの配置・トリミング・拡大と文字サイズの調整
- `public/screenshots/`：提供された元スクショ（変更せず保持）
- `CHANGES.md`：変更点・根拠コミットの記録
- `../theme/`：共通の作成環境・レイアウト・ロゴを提供する submodule
- `../../source/_posts/JRShikokuAppsArchive/7.3-update.md`：記事本文（2026年10月17日）
- `../../source/assets/JRShikokuAppsArchive/7.3/`：掲載用PNG

初回セットアップは `slides/README.md` を参照。
ブログリポジトリのルートで `npm run slides:7.3` を実行すると、
テーマ側の環境だけで掲載用画像を直接生成する（1920×1080）。
テーマ指定・見出し補完・ロゴの差し替えを記事側で行う必要はない。

## 編集と確認

1. `slides.md` の本文や画像パスを編集する
2. 必要に応じて `style.css` の切り出し範囲を調整する
3. ブログのルートで `npm run slides:7.3` を実行する
4. 記事の文章と画像の対応を確認し、`npm run build` でブログを生成する
5. `npm run server` でカバーと本文画像を確認する
